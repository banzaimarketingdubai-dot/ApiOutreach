# Frontend UI/UX и Адаптация под Telegram (React)

Инструкции по разработке клиентской части платформы.

## 1. Технологический Стек (Frontend)
*   **Фреймворк:** React 18+ (Сборка через Vite для скорости).
*   **Роутинг:** React Router DOM (v6).
*   **Стейт Менеджмент:** Zustand (легковесный) + React Query (для кеширования API запросов).
*   **UI Библиотека:** `shadcn/ui` + `TailwindCSS` (позволяет быстро собрать современный, строгий дашборд без тяжелых зависимостей вроде MUI/AntD).
*   **Иконки:** Lucide React.

## 2. Структура Views (Экраны)

### 2.1. Дашборд (Home)
*   **KPI Cards:** Всего лидов, Лиды с WhatsApp, Активные задачи.
*   **Диаграммы (Recharts):** Распределение лидов по нишам и ГЕО.

### 2.2. Запуск Сбора (Task Builder)
*   Компонент формы (`react-hook-form` + `zod` для валидации).
*   Селекты: Выбор гео (Дубай, Киев, кастом), выбор ниш (мульти-селект).
*   Чекбоксы модулей: "Использовать Apify", "Парсить сайты", "Искать WhatsApp".
*   Кнопка "Launch Pipeline".
*   Ниже - таблица активных задач с живыми прогресс-барами (Polling API `/tasks`).

### 2.3. Master Data (База Лидов)
*   Самый сложный компонент: **Data Grid (Таблица)**. Рекомендуется использовать `TanStack Table` (React Table v8).
*   Колонки: Название, Тип, Город, Revo Score, Контакты (Иконки: ✉️, 📞, 💬, 📸 - подсвечиваются, если контакт найден), Статус.
*   **Global Filter Panel:** Панель с мощными фильтрами над таблицей (фильтрация по скору, по наличию мессенджера).
*   Кнопка "Export to CSV" (Обращение к API экспорта).

### 2.4. Детальная Карточка Лида (Modal / Drawer)
При клике на строку в таблице выезжает боковая панель (Drawer).
*   **Шапка:** Название, лого (если есть), кнопки перехода на сайт / карты.
*   **Блок "Контакты":** Красиво сгруппированные бейджи с телефонами, email и мессенджерами. Кликабельно (копирование).
*   **Блок "Revo Audit":** Инфографика/текст о проблемах карточки.
*   **История обогащений:** Таймлайн (Когда добавлен, когда спарсен сайт).

## 3. Адаптация под Telegram Mini App (TMA)
Так как менеджеры часто работают с телефона, интерфейс должен встраиваться внутрь Telegram WebApp.

### Требования к TMA:
1.  **Инициализация:** Подключение скрипта `https://telegram.org/js/telegram-web-app.js`.
2.  **Темизация:** Цвета Tailwind должны подтягиваться из глобального объекта `window.Telegram.WebApp.themeParams` (Поддержка светлой/темной темы телеграма).
3.  **Адаптивность (Mobile-First):** 
    *   В мобильной версии таблица (Data Grid) превращается в список карточек (List View).
    *   Кнопка "Запустить парсинг" выносится в `window.Telegram.WebApp.MainButton` для нативности.
4.  **Авторизация:** Бесшовная авторизация через проверку `initData` на бекенде FastAPI (не нужно вводить логин/пароль).
